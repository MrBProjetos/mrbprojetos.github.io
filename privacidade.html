Política de Privacidade

Mr. B Reader · última atualização: 24 de novembro de 2026

Esta política explica quais dados o Mr. B Reader usa e como. Ela vale para as duas versões: a de navegador (em mrbprojetos.github.io/leitor, no computador ou no celular) e o programa de Windows. Em resumo: o leitor funciona no seu aparelho, não tem servidor próprio e só acessa o seu Google Drive se você pedir. Mesmo nesse caso, acessa apenas os arquivos que ele mesmo criou.

1. Quem é o responsável

O Mr. B Reader é um projeto pessoal de Brayhan Emelton Muller. Contato: brayhanemelton99@gmail.com.

2. Dados guardados no seu computador

Para lembrar onde você parou, o programa guarda no próprio computador, na pasta %APPDATA%\Leitor:

  • a lista dos livros abertos e onde eles estão no disco;
  • a posição de leitura, os destaques, as notas e as pastas que você criou;
  • as capas dos livros, a imagem de fundo escolhida e as preferências de aparência.

Esses dados não são enviados ao desenvolvedor nem a terceiros.

Na versão de navegador, os mesmos dados (inclusive uma cópia dos livros que você abre, para poder reabri-los) ficam guardados no armazenamento do próprio navegador, só no aparelho que você está usando. O site é feito só de arquivos fixos, hospedados no GitHub Pages; os livros e as anotações nunca são enviados ao site. Como em qualquer site, o GitHub pode registrar dados técnicos de acesso (como o endereço IP) segundo a política de privacidade dele.

3. Google Drive (opcional)

Se você clicar em "Entrar com o Google", o programa pede as permissões abaixo. Elas são as mínimas necessárias:

  • drive.file: criar e usar somente os arquivos que o próprio Mr. B Reader criou no seu Drive. São as cópias dos seus livros, na pasta "Mr. B Reader" e nas subpastas que você criar. O programa não consegue ver nem alterar nenhum outro arquivo do seu Drive.
  • drive.appdata: usar a área oculta do Drive reservada ao app. Nela ficam o índice da biblioteca (marcações, notas, posições de leitura, pastas) e as capas.
  • openid e e-mail: mostrar no programa qual conta do Google está conectada.

Esses dados vão direto do seu computador para o seu Google Drive. Eles não passam por nenhum servidor do Mr. B Reader, porque ele não tem servidor. No programa de Windows, a autorização dada pelo Google fica guardada no seu computador, criptografada pelo Windows. Na versão de navegador, o Google entrega uma autorização que vale por 1 hora e fica guardada só naquele navegador; depois disso o leitor pede uma nova ao Google. O leitor nunca vê a sua senha: o login é feito no site do Google.

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google pelo Mr. B Reader seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Mr. B Reader's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. Links, tradução e atualização

Quando você clica num link da internet dentro de um livro, ou em "Definir", "Traduzir" ou "Pesquisar" sobre um trecho selecionado, o endereço abre no seu navegador (Google, Google Tradutor ou o site do link). Só o trecho que você escolheu é enviado, e só nesse clique. As estatísticas de leitura (tempo e páginas por dia) ficam no seu aparelho; o tempo de cada livro vai para o seu Google Drive junto com as anotações, se a nuvem estiver ligada.

O programa de Windows procura versão nova num arquivo fixo do site (mrbprojetos.github.io), sem enviar nenhum dado seu. Dá para desligar essa busca no menu da biblioteca.

5. O que nunca fazemos

  • Vender, alugar ou compartilhar seus dados.
  • Usar seus dados para publicidade.
  • Usar seus dados para treinar modelos de inteligência artificial.
  • Ler arquivos do seu Drive que não foram criados pelo Mr. B Reader.

6. Como desconectar e apagar seus dados

  • Desconectar: no leitor, use o botão da nuvem → "Sair da conta". Também é possível remover o acesso em myaccount.google.com/permissions.
  • Apagar do Drive: apague a pasta "Mr. B Reader" do seu Drive. Para apagar a área oculta do app, abra o Google Drive no navegador → Configurações → Gerenciar apps → Mr. B Reader → Opções → "Excluir dados de app ocultos".
  • Apagar do computador: desinstale o programa e marque a opção de apagar marcações, notas e configurações. Outra forma é apagar a pasta %APPDATA%\Leitor.
  • Apagar do navegador: remova os livros da biblioteca, ou apague os dados do site mrbprojetos.github.io nas configurações do navegador (no celular, também dá para desinstalar o app da tela inicial).

7. Mudanças nesta política

Se esta política mudar, a data no topo da página será atualizada.
